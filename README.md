Shopkart - E-commerce app

# Installation

git clone https://github.com/madhankumar1192000/ecommerce-shopkart
cd myshop
npm install
npm run dev

# React E-Commerce Frontend

Here you can find a responsive e-commerce frontend built using **React.js**, with core shopping features like product browsing, search, sorting, category filtering, a shopping cart, and checkout functionality. Data is fetched from a public API for demonstration.

# Features

- **Search** for products by name
- **Sort** products by price (ascending/descending)
- **Filter** by category
- **Add to Cart** and view cart contents
- **Checkout** with total calculation
- Integrated with [Fake Store API](https://fakestoreapi.com/)
- Fully **responsive** layout using CSS
- State management using **React Hooks**
